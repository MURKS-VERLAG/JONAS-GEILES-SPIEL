# Karate Andrus – Version 1.0

Ein kleines browserbasiertes 2D-Spiel mit den beiden Originalbildern.

## Steuerung
- W/A/S/D oder Pfeiltasten: Bewegung in alle Richtungen
- Leertaste: Sprung mit weißem Staubeffekt
- 1/2/3 oder Schaltflächen: drei Zoomstufen

## GitHub Pages
1. ZIP entpacken.
2. Alle Dateien inklusive `assets` in das Stammverzeichnis eines GitHub-Repositories hochladen.
3. Unter **Settings → Pages → Build and deployment** `Deploy from a branch`, Branch `main`, Ordner `/ (root)` auswählen und speichern.
4. Die anschließend angezeigte GitHub-Pages-URL öffnen.

Hinweis: Die Spielfigur verwendet derzeit ein einzelnes Originalbild. Die Laufbewegung wird durch leichtes Wippen und Neigen simuliert. Die Karte ist eine flache 2D-Fläche; Kollisionen mit Bäumen sind noch nicht implementiert.
